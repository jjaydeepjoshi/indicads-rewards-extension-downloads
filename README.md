# IndicAds Rewards: downloads

Release files of the IndicAds Rewards browser extension for Chrome and Edge, by Binarius Systems Private Limited.

Download and install guide: **https://www.binarius.co.in/extensions/**

Each release has `indicads-rewards-<version>.zip`. Unzip it, open `chrome://extensions` or `edge://extensions`, turn on
**Developer mode**, click **Load unpacked** and choose the unzipped folder.

This repository contains only release files, no source code.
